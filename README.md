# Zenso Starter Plugin

A clean starter widget and reference implementation for the Zenso e-ink ecosystem.

## Description

This plugin displays a customizable welcome message alongside the current device time and date, beautifully laid out for multi-color and grayscale e-paper screens.

## Settings

When configuring this widget in Zenso Panel, the following options are available:

- **Widget Title**: Custom greeting or header text (e.g., `"Good Morning"`, `"Hello"`).
- **Show Footer**: Toggles the display of the bottom status bar and timestamp info.
